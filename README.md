# Wi‑Fi | 4G Enhanced – Magisk Module

**Universal network tweak for Android 11–14: faster Wi‑Fi, lower ping, stable VPN.**

## Features
- TCP buffer optimizations for LTE / Wi‑Fi / VPN
- Westwood (or BBR) congestion control
- TCP Fast Open, disable slow-start after idle
- VoLTE/VoWiFi hints for Qualcomm devices
- Safe: checks every file before writing, logs everything

## Compatibility
- Any device with Magisk 23+ / KernelSU / APatch
- Tested on Poco F3 (Android 13), works on Samsung, Pixel, OnePlus, etc.

## Installation
1. Download `wifienhan_vX.X.zip` from Releases
2. Install in Magisk → "Install from storage"
3. Reboot
4. Check log: `/data/local/tmp/wifi_enhance.log`
